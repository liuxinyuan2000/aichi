接入文档

获取密钥后，把地址和模型填到客户端即可开始调用。

  1. 创建 API 密钥

    登录后打开密钥管理，选用管理员分配的分组。配额和过期时间可按需设置。

  2. 填写网关地址

    OpenAI 兼容客户端使用 /v1。在调用示例切换协议可查看对应路径和鉴权方式。

  3. 检查调用和用量

    把示例里的 MODELPORT_KEY 和 MODEL_ID 换成你的密钥和模型。在用量记录查看请求、Token 和费用。
